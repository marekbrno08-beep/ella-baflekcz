# Obrázky

Sem patří obrazová část webu. Názvy souborů odpovídají tomu, co je
už nalinkované v HTML — stačí je nahrát se stejným jménem.

| Soubor | Kde se používá | Doporučená velikost |
|---|---|---|
| `ella-portret.jpg` | hero na hlavní stránce | 900 × 1125 px (4:5) |
| `ella-o-mne.jpg` | sekce „O mně“ | 800 × 1066 px (3:4) |
| `nahled-1.jpg` … `nahled-5.jpg` | náhledy videí | podle poměru videa (9:16 nebo 16:9) |
| `og-image.jpg` | náhled při sdílení odkazu | 1200 × 630 px |
| `apple-touch-icon.png` | ikona na iPhonu | 180 × 180 px |
| `icon-192.png`, `icon-512.png` | ikony pro manifest | 192 a 512 px |

`favicon.svg` a `og-image.svg` jsou hotové. `og-image.svg` je potřeba
vyexportovat do `og-image.jpg` — sociální sítě SVG náhledy nezobrazují.
Export zvládne třeba https://cloudconvert.com nebo Figma.

Fotky před nahráním zmenši (šířka max ~1600 px) a ideálně převeď do
formátu `.webp` — web pak bude výrazně rychlejší.
